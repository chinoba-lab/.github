# Experiments

## What this is

An experiment is where an idea meets reality. A [proposal](../proposals/) or a
[research note](../notes/) makes a claim; an experiment tests it, records what
actually happened, and keeps the lesson — whether the result confirmed the claim
or refuted it.

> Research is a continuous process. An experiment is one turn of it: a hypothesis
> in, a lesson out, and often a new question that sends the idea back to
> [discussion](../discussions/).

---

## Negative results are kept

An experiment that fails is not deleted. A hypothesis that turned out to be wrong
is knowledge — often more useful than one that was right — and it stays in the
open record. Hiding negative results would break the very trace the Laboratory
exists to keep.

---

## What an experiment contains

Experiments follow [`../../templates/experiment-template.md`](../../templates/experiment-template.md):

| Section | Purpose |
|---|---|
| **Hypothesis** | What we expected, stated before running |
| **Method** | How the experiment was set up |
| **Implementation** | What was actually built or run |
| **Observations** | What happened |
| **Result** | Whether the hypothesis held |
| **Lessons Learned** | What we now know |
| **Open Questions** | What the experiment raised |

---

## Where an experiment leads

```
Hypothesis → Experiment → Result → Lessons → (Revision · new Discussion · Paper)
```

A result can feed a [paper](../papers/), revise an [architecture](../architectures/),
or open a fresh [discussion](../discussions/). The lesson always outlives the
run.
