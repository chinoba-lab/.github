---

## What this is

The **Research Hub** is the navigation layer of Chinoba. It sits between three
surfaces and keeps them pointing at each other:

- **Chinoba.org research pages** — where each idea is explained.
- **GitHub open-source repositories** — where each idea becomes code.
- **Future implementations** — where each idea is heading next.

It does **not** restate the research and it does **not** define governance,
architecture, or standards. Those already exist elsewhere in this workspace and
stand unchanged. This section is purely a **map**: a single, consistent entry
point into every research area.

> **Intelligence is relational.** A map is the relationship between where you
> are and where you can go. This hub is that relationship for Chinoba's research.

---

## How every research area is organized

Each research area has its own page in this hub, and each page is built from the
same three-part promise:

| Part | Question it answers |
|---|---|
| **Research Page** | What is the idea? → the corresponding page on Chinoba.org |
| **Open Source Projects** | Where does the idea live as code? → the OSS repositories |
| **Future Roadmap** | Where is the idea going next? → planned implementations |

Every page links back here and out to its neighbors, so the research reads as
one connected field rather than a list of topics.

## Status

This Research Hub is intended to **evolve over time** as repositories are
created. Every OSS entry currently reads **Planned Repository (TBD)** — no
repository names are invented here. As each project graduates from the Bench to
the Commons, its row is updated with the real repository link.
