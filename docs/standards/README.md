# Standards

*What every official Chinoba repository must meet.*

Standards are the difference between the Bench and the Commons. On the Bench,
anything goes; on the Commons, everything is held to a shared bar. These
standards are **derived from the existing Chinoba documentation** — they
codify the voice, structure, and discipline that the existing `docs/` already
demonstrate.

## The standards in one breath

> Every official repo reads like it belongs to the same project, can be picked
> up by a stranger, names its owner, and meets the bar before — not after — it
> graduates.

A repository that cannot meet these standards is, by definition, still on the
Bench. The standards *are* the graduation gate, expressed concretely.
